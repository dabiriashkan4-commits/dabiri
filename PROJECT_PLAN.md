# Project plan

## Objective

Provide a deployable demonstration of a gold-market analysis hub while making it impossible to confuse demo values with live or executable market data.

## Deliverables

1. Deterministic synthetic analysis engine.
2. Strict JSON result artifact.
3. Persian/RTL standalone dashboard with Plotly and Vazirmatn.
4. FastAPI routes plus safe ASGI fallback.
5. Render Blueprint, Procfile and minimal dependency list.
6. Unit, compilation and ASGI smoke validation.

## Safety boundary

No broker connection, order placement, credential, live feed, position sizing or outcome guarantee is included.
